# Wisconsin Windigo Ice Rink Management System

A React + Vite dashboard for managing teams, rink conditions, maintenance requests, and billing forms for a professional arena operation.

## Run locally

```bash
npm install
npm run dev
```

## Features

- Responsive landing dashboard
- Teams dashboard with filters and tables
- Ice and maintenance analytics
- Rink building information forms
- Maintenance and billing workflows
- Wisconsin Windigo-inspired theme
